# Project vignettes

Eight self-contained SVG concept animations for Ethan Chen's GitHub profile.
The editor framing and terminal rhythm draw design inspiration from
[Timcai06's profile](https://github.com/Timcai06). The skyline, previews,
project copy and SVG implementation were created for this profile.

Regenerate with `python scripts/build_project_art.py` from the repository root.
Only Python's standard library is required. Each SVG includes its own CSS,
accessible title and description, and a static reduced-motion presentation.

Terminal commands and preview content illustrate capabilities. They are
concept sketches rather than screenshots, execution logs or live metrics.
The existing pixel coding room remains the profile's main illustration.
