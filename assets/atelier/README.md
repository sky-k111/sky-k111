# Project vignettes

Eight self-contained SVG concept animations for Ethan Chen's GitHub profile.
The editor framing and terminal rhythm draw design inspiration from
[Timcai06's profile](https://github.com/Timcai06). The skyline, previews,
project copy and SVG implementation were created for this profile.

Regenerate with `python scripts/build_project_art.py` from the repository root.
Only Python's standard library is required. Each SVG includes its own CSS,
accessible title and description, and a static reduced-motion presentation.

Four terminal vignettes show documented startup commands:

- EduCanvas: `make doctor`, then `make all` at the repository root.
  Source: [runtime.mk](https://github.com/Timcai06/EduCanvas/blob/main/tooling/make/runtime.mk).
- ForgeSight: enter the cloned `forge-sight` directory and run `.\fs.bat` on Windows.
  Source: [Quick start](https://github.com/sky-k111/forge-sight#快速开始).
- 名笺: enter `frontend` and run `npm run dev` after dependencies are installed.
  Source: [Quick start](https://github.com/sky-k111/ai-name#快速开始).
- Portfolio V5: `npm install`, then `npm run dev` at the repository root.
  Source: [package.json](https://github.com/sky-k111/my-profile-v5/blob/main/package.json).

Startup snippets assume the repositories' documented environment setup.
Other terminal text and all previews illustrate project capabilities.
The animations are concept sketches rather than execution logs or live metrics.
The existing pixel coding room remains the profile's main illustration.
